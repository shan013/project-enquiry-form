# Project Inquiry Form

A modern multi-step project inquiry form built with Next.js, React, TypeScript, and CSS.

This project was created as a frontend-focused learning project to practice building interactive forms and understanding modern React and Next.js development.

## Features

* Multi-step project inquiry form
* Step-by-step navigation
* Back and Edit navigation
* Client-side form validation
* Conditional rendering
* Controlled React form inputs
* Project type selection
* Budget and timeline selection
* Review screen before submission
* Animated success screen
* Responsive design
* Premium, minimal UI

## Tech Stack

* Next.js
* React
* TypeScript
* CSS
* Vercel

## Project Flow

1. Your Details
2. Project Type
3. Project Details
4. Budget & Timeline
5. Review & Submit
6. Submission Success

## Note

This is a frontend-only project.

The submission flow currently displays a success screen but does not send the submitted information to a backend, database, or email service.

## Deployment

The project is deployed using Vercel.

## Learning Goal

This project was built to gain practical experience with React and Next.js, including component rendering, state management, form validation, event handling, conditional rendering, and deployment.
